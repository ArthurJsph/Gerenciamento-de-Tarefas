## Gerenciador de Tarefas

### Descrição
O **Gerenciador de Tarefas** é uma aplicação web que permite aos usuários criar, editar, excluir e gerenciar suas tarefas diárias de forma eficiente. Com uma interface intuitiva, os usuários podem organizar suas atividades, definir prazos e acompanhar o progresso de suas tarefas.

### Tecnologias Utilizadas
- **Backend:** Java, Spring Boot
- **Frontend:** HTML, CSS, JavaScript
- **Banco de Dados:** MySQL
